# kotlin-lotto-precourse

## 프로젝트 소개
1~45 범위의 숫자 중 중복되지 않는 6개의 번호로 구성된 로또를 구매하고, 당첨 번호와 비교하여 당첨 결과를 확인하는 로또 게임 프로그램입니다.

## 주요 기능
- 로또 구매 금액 입력 및 자동 로또 발행
- 당첨 번호 및 보너스 번호 입력
- 당첨 결과 집계 및 수익률 계산
- 예외 상황 처리 및 재입력

## 게임 규칙

### 로또 번호
- 로또 번호는 1~45 범위의 숫자
- 1개의 로또는 중복되지 않는 6개의 숫자로 구성
- 로또 1장의 가격은 1,000원

### 당첨 등수
| 등수 | 당첨 조건 | 당첨 금액 |
|------|----------|----------|
| 1등 | 6개 번호 일치 | 2,000,000,000원 |
| 2등 | 5개 번호 + 보너스 번호 일치 | 30,000,000원 |
| 3등 | 5개 번호 일치 | 1,500,000원 |
| 4등 | 4개 번호 일치 | 50,000원 |
| 5등 | 3개 번호 일치 | 5,000원 |

## 📋 기능 목록

#### 1. 로또 번호 도메인
- 1~45 범위의 로또 번호 생성 기능
- 로또 번호 범위 검증 기능 (1 ≤ n ≤ 45)
- 로또 번호 정렬 기능

#### 2. 로또 생성
- 6개의 중복되지 않는 로또 번호 생성 기능
- 로또 번호 6개 검증 기능
- 로또 번호 중복 검증 기능
- 로또 번호 오름차순 정렬 기능 

#### 3. 당첨 등수 판정
- 당첨 등수 Enum 정의 (1등~5등, 일치 개수, 상금)
- 일치 개수로 등수 판정 기능 
- 보너스 번호 일치 여부로 2등 판정 기능

#### 4. 구매 금액 도메인
- 구매 금액 숫자 형식 검증 기능
- 구매 금액 1,000원 단위 검증 기능
- 구매 금액 최소 금액(1,000원) 검증 기능
- 구매 금액으로 로또 개수 계산 기능

#### 5. 로또 발행
- 로또 자동 생성 기능
- 여러 로또 자동 생성 기능 
- 구매한 로또 목록 저장 기능 
- 구매한 로또 개수 조회 기능

#### 6. 당첨 번호 도메인
- 당첨 번호 파싱 기능 (쉼표 구분, 공백 무시)
- 당첨 번호 6개 검증 기능
- 당첨 번호 숫자 형식 검증 기능
- 당첨 번호 1~45 범위 검증 기능
- 당첨 번호 중복 검증 기능

#### 7. 보너스 번호 도메인
- 보너스 번호 생성 기능
- 보너스 번호 1~45 범위 검증 기능
- 보너스 번호와 당첨 번호 중복 검증 기능

#### 8. 당첨 결과 계산
- 로또 번호와 당첨 번호 일치 개수 계산 기능
- 보너스 번호 일치 여부 확인 기능
- 개별 로또의 당첨 등수 판정 기능 

#### 9. 당첨 통계 집계
- 등수별 당첨 개수 집계 기능 
- 총 당첨 금액 계산 기능
- 수익률 계산 기능 (소수점 둘째 자리 반올림)

#### 10. 입력 기능 (InputView)
- 구매 금액 입력 기능 
- 구매 금액 입력 재시도 기능 
- 당첨 번호 입력 기능 
- 당첨 번호 입력 재시도 기능 
- 보너스 번호 입력 기능 
- 보너스 번호 입력 재시도 기능 

#### 11. 출력 기능 (OutputView)
- 구매한 로또 개수 출력 기능
- 구매한 로또 번호 목록 출력 기능
- 당첨 통계 헤더 출력 기능
- 등수별 당첨 내역 출력 기능 (5등→1등)
- 총 수익률 출력 기능
- 에러 메시지 출력 기능

#### 12. 게임 흐름 제어 (LottoController)
- 로또 구매 흐름 (입력 → 검증 → 발행 → 출력)
- 당첨 번호 입력 흐름 (입력 → 검증)
- 보너스 번호 입력 흐름 (입력 → 검증)
- 당첨 결과 계산 및 출력 흐름
- 예외 발생 시 재입력 처리

#### 13. 메인 실행 (Application)
- 게임 시작 및 종료 처리

## 예외 처리

모든 예외는 `IllegalArgumentException`을 발생시키며, "[ERROR]"로 시작하는 메시지를 출력합니다.

### 구매 금액 예외
- 숫자가 아닌 값 입력
- 1,000원 단위가 아닌 금액
- 1,000원 미만의 금액

### 당첨 번호 예외
- 6개가 아닌 번호 개수
- 숫자가 아닌 값 포함
- 1~45 범위를 벗어난 번호
- 중복된 번호

### 보너스 번호 예외
- 숫자가 아닌 값
- 1~45 범위를 벗어난 번호
- 당첨 번호와 중복
